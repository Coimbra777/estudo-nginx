# F05 — Contrato

## Provê

Redis como cache/sessão/fila ativos para o container `laravel`. Sem API HTTP nova —
esta feature não muda nenhum contrato consumido por outro serviço.

## Consome

Nada.

## Consumido por

Nenhuma outra feature depende diretamente de F05. É uma correção de configuração
isolada ao Laravel.
